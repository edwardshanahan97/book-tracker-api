# Book Tracker API

A learning project for building a REST API with Node.js, Express, PostgreSQL, and SQL.

## Current Progress

The PostgreSQL database currently includes:

- Books
- Authors
- Genres
- One-to-many relationships
- Many-to-many relationships using a `book_genres` junction table
- Foreign keys and constraints
- SQL JOIN practice

## Next Steps
- Connect Node.js and Express to PostgreSQL using pg
- Build REST API endpoints
- Implement CRUD operations
- Query books with their authors and genres
